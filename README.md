# heritage-guide

문화유산 감정 현장에서 외국인 여행자에게 절차를 안내하기 위한 **다국어 안내 도구**입니다. 국가유산청 문화유산감정관실의 공항 감정 현장(반출 검색대·방문 감정)에서 사용하도록 만들었습니다.

단일 HTML 파일로 동작하며 별도 설치나 서버가 필요 없습니다. 인터넷 연결 없이도 텍스트 안내가 표시되며, 음성 출력은 기기에 설치된 TTS 엔진을 이용합니다.

---

## 배경

공항 감정 현장에서는 한국어가 통하지 않는 여행자에게 같은 절차를 반복해서 설명해야 합니다. 비문화유산 확인, 일반동산문화유산 반출 불허, 임의제출, 임시보관 등은 법적 고지 사항을 정확히 전달해야 하므로 즉석 통역에 의존하기 어렵습니다.

이 도구는 현장에서 자주 쓰이는 안내 멘트를 미리 5개 언어로 번역해 두고, 버튼 하나로 화면에 표시하고 음성으로 재생합니다. 감정위원은 한국어 원문을 참고하면서 외국어 멘트를 여행자에게 보여 주거나 들려줄 수 있습니다.

## 주요 기능

- **5개 언어 지원** — 영어, 일본어, 중국어, 독일어, 프랑스어. 상단 언어 토글로 즉시 전환됩니다.
- **11개 시나리오 분류** — 도입부터 마무리까지 감정 절차 흐름에 따라 멘트가 정리되어 있습니다.
- **한국어 원문 병기** — 화면 하단에 감정위원 참고용 한국어 원문이 함께 표시됩니다.
- **음성 출력(TTS)** — 선택한 멘트를 해당 언어 음성으로 재생합니다. 음성 데이터가 없는 기기에서는 미지원 안내가 표시되고 텍스트는 정상 작동합니다.
- **모바일 최적화** — 휴대폰 화면에 맞춘 반응형 레이아웃이며, 홈 화면에 추가하면 앱처럼 실행됩니다.
- **오프라인 표시** — 외부 폰트를 제외한 안내 텍스트는 네트워크 없이 동작합니다.

## 안내 멘트 구성

감정 절차 흐름에 따라 11개 분류로 멘트가 정리되어 있습니다. 도입과 절차 안내, 신청서 거부 시 응대, 감정 진행, 결과 통지, 임의제출 절차와 비협조 시 대응을 거쳐, 일반동산문화유산 해당 기준을 설명하는 분류 설명과 현장 실무용 보조 멘트까지 포괄하며, 일부 멘트에는 사용 조건 배지가 붙어 있습니다.

구체적인 멘트 문안은 `index.html` 내부의 `groups` 배열에서 확인할 수 있습니다.

## 사용법

1. 휴대폰이나 태블릿 브라우저에서 `index.html`을 엽니다.
2. 상단에서 응대할 여행자의 언어를 선택합니다.
3. 현재 절차에 맞는 멘트 버튼을 누릅니다.
4. 화면에 외국어 멘트가 표시되며, **Play Audio** 버튼으로 음성 재생이 가능합니다.
5. 감정위원은 하단의 한국어 원문을 참고합니다.

> **홈 화면에 추가** — iOS Safari·Android Chrome에서 공유 메뉴를 통해 홈 화면에 추가하면 주소창 없는 전체 화면 앱으로 실행됩니다.

## 음성이 나오지 않을 때

음성 출력은 브라우저와 기기에 설치된 TTS(음성 합성) 엔진에 의존합니다. **텍스트 표시는 음성과 무관하게 항상 작동**하므로, 음성이 안 되더라도 화면의 멘트를 직접 보여 주는 방식으로 사용할 수 있습니다.

**권장 브라우저 — 크롬, 엣지.** 두 브라우저는 자체 음성 데이터(클라우드 음성 포함)를 갖고 있어 5개 언어 모두 안정적으로 재생됩니다.

**네이버 웨일 등에서 음성이 안 되는 경우.** 웨일을 비롯한 일부 크로미움 계열 브라우저는 크롬의 내장 음성을 쓰지 못하고 운영체제에 설치된 음성만 사용합니다. 윈도우에 일본어·중국어·독일어·프랑스어 음성 데이터가 없으면 해당 언어 재생이 되지 않습니다. 해결 방법:

- 크롬 또는 엣지로 전환 — 가장 간단하고 확실합니다.
- 윈도우 언어팩 설치 — 설정 → 시간 및 언어 → 언어 및 지역 → 언어 추가 시 음성 데이터를 함께 설치합니다.

**안드로이드에서 음성이 안 되는 경우.** 설정 → 일반 → 텍스트 음성 변환(TTS) → Google 음성 엔진을 선택한 뒤, 필요한 언어 데이터를 내려받습니다.

**음성 미지원 안내.** 선택한 언어의 음성이 기기에 없으면 앱이 빨간색 안내 문구를 표시합니다. 이 경우 텍스트만 사용하거나 위 방법으로 음성 데이터를 추가하면 됩니다.

## 번역 용어 원칙

- 일본어·중국어 일반 안내문은 현지 표준 용어(`文化財`·`文物`)를 사용합니다.
- 한국 법령을 인용하는 문장에서는 정식 직역(`文化遺産`·`文化遗产`)을 유지하고, 필요한 경우 현지 용어를 괄호로 보충합니다.

## 법적 근거

안내 멘트는 다음 법령을 근거로 작성되었습니다.

- 「문화유산의 보존 및 활용에 관한 법률」 제60조·제90조
- 「형사소송법」 제129조·제211조·제212조·제216조
- 「경찰범죄수사규칙」 제23조

## 배포

GitHub Pages로 배포할 수 있습니다.

1. 저장소 **Settings → Pages** 진입
2. **Source**를 `Deploy from a branch`로 설정
3. 브랜치를 `main`, 폴더를 `/ (root)`로 지정 후 저장
4. 잠시 후 `https://<사용자명>.github.io/heritage-guide/` 주소로 접속

## 파일 구성

```
heritage-guide/
├── index.html   # 앱 본체 (HTML·CSS·JS·멘트 데이터 일체 포함)
└── README.md
```

모든 안내 멘트 데이터는 `index.html` 내부의 `groups` 배열에 들어 있습니다. 멘트를 추가·수정하려면 이 배열을 편집하면 됩니다. 각 항목은 `ko`, `en`, `ja`, `zh`, `de`, `fr` 키에 언어별 문구를 담습니다.

## 면책

이 도구는 현장 안내 보조용입니다. 표시되는 멘트는 일반적 절차 안내이며, 개별 사건의 법적 처분은 관련 법령과 감정위원의 판단에 따릅니다.
